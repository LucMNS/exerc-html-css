CSS BACKGROUNDS

Construindo fundos com CSS

Fundos bem planejados criam atmosfera, organizam a página e ajudam a destacar seu conteúdo.

Background-color

Esta seção utiliza uma cor de fundo sólida. Ela cria uma base limpa e mantém o texto com alto contraste para facilitar a leitura.

Background-image

Aqui uma imagem de montanhas é usada como fundo. A sobreposição escura e o texto claro garantem que o conteúdo continue legível.

Posicionamento e repetição

Este fundo usa um padrão de pontos repetido com background-repeat e deslocado com background-position. O padrão é decorativo e não interfere na leitura do texto.
