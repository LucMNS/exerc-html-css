Praticando a sintaxe do CSS

Como uma regra CSS transforma a página

O CSS permite alterar a aparência de elementos HTML por meio de regras organizadas e fáceis de reutilizar.

Cada regra possui um seletor, uma propriedade e um valor. Juntos, eles informam ao navegador qual elemento deve ser estilizado e como.

Observe as cores, os tamanhos, os espaços e o alinhamento aplicados a este exercício pelo arquivo CSS.
