Código do Exercício 01: index.html


<!doctype html>
<html lang="pt-br">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="stylesheet" href="style.css" />
    <title>Praticando a sintaxe do CSS</title>
  </head>
  <body>
    <main class="pagina">
      <h1>Praticando a sintaxe do CSS</h1>
      <h2>Como uma regra CSS transforma a página</h2>

      <p>
        O CSS permite alterar a aparência de elementos HTML por meio de regras
        organizadas e fáceis de reutilizar.
      </p>
      <p>
        Cada regra possui um seletor, uma propriedade e um valor. Juntos, eles
        informam ao navegador qual elemento deve ser estilizado e como.
      </p>
      <p class="destaque">
        Observe as cores, os tamanhos, os espaços e o alinhamento aplicados a
        este exercício pelo arquivo CSS.
      </p>
    </main>
  </body>
</html>

style.css


/* Sintaxe: seletor { propriedade: valor; }
	 O seletor escolhe o elemento, a propriedade indica o que mudar e o valor
	 define como essa mudança será aplicada. */

/* Esta regra define a aparência geral da página. */
body {
  margin: 0;
  padding: 32px 20px;
  color: #243447;
  background-color: #edf4f2;
  font-family: Verdana, sans-serif;
  font-size: 17px;
  line-height: 1.6;
}

/* Esta regra limita a largura e centraliza o conteúdo. */
.pagina {
  max-width: 820px;
  margin: 0 auto;
  padding: 36px;
  background-color: #ffffff;
  border-top: 8px solid #287271;
  border-radius: 8px;
  box-shadow: 0 8px 20px rgb(22 78 99 / 12%);
}

/* O título recebe cor, tamanho e alinhamento próprios. */
h1 {
  margin: 0 0 12px;
  color: #164e63;
  font-size: 2.4rem;
  text-align: center;
}

/* O subtítulo usa outra cor para criar uma hierarquia visual. */
h2 {
  margin: 0 0 24px;
  color: #b26e00;
  font-size: 1.25rem;
  font-weight: normal;
  text-align: center;
}

p {
  padding: 16px;
  margin: 0 0 16px;
  background-color: #f5f9f8;
  border-left: 4px solid #81b29a;
}

.destaque {
  color: #164e63;
  background-color: #fff5df;
  border-left-color: #f4c95d;
  font-weight: bold;
  text-align: center;
}

@media (max-width: 560px) {
  body {
    padding: 24px 14px;
    font-size: 16px;
  }

  .pagina {
    padding: 24px 18px;
  }

  h1 {
    font-size: 1.9rem;
  }
}
