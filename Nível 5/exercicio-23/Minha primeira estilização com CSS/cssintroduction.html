Minha primeira estilização com CSS

HTML organiza o conteúdo e CSS transforma sua aparência.

Conteúdo da página

Esta página foi criada com HTML e estilizada usando um arquivo CSS externo. A cor do texto, o fundo, o tamanho da fonte e o alinhamento foram definidos no arquivo style.css.

Este parágrafo também recebeu estilo do CSS externo e mostra como uma classe pode ser reutilizada.

Três formas de usar CSS

  • CSS externo: fica em um arquivo separado, como o style.css, e pode ser usado em várias páginas.
  • CSS interno: fica dentro da tag <style> no próprio HTML e vale para aquela página.
  • CSS inline: fica no atributo style do elemento e altera somente aquele item.

Este texto é um exemplo de CSS inline.
