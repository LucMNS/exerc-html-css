CSS SELECTORS

Laboratório de seletores CSS

Compare como cada seletor encontra e estiliza elementos da página.

Seletores em ação

  • Elemento: seleciona todas as tags do mesmo tipo.
  • Classe: seleciona qualquer elemento com a mesma classe.
  • ID: seleciona um elemento único da página.
  • Agrupado: aplica a mesma regra a vários seletores.
  • Descendente: seleciona elementos dentro de outro elemento.
