Exercício 05 - Frases e citações famosas

Conteúdos: HTML Quotations.

Objetivo: Aprender elementos relacionados a citações.

Atividade:

Crie uma página contendo três frases ou citações famosas.

Requisitos:

  • Utilizar as tags <blockquote>, <q>, <cite> e <abbr>.
  • Identificar o autor de cada citação.

Desafio:

Adicione uma abreviação que mostre seu significado quando o mouse estiver sobre ela.
