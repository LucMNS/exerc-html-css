Código do Exercício 01: index.html


<!doctype html>
<html lang="pt-br">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Hierarquia dos Títulos</title>
  </head>
  <body>
    <ol>
      Lista da hierarquia dos títulos HTML
      <dl>
        <li>
          <dt>
            <h1>h1</h1>
          </dt>
        </li>
        <dd>
          O elemento h1 representa o título principal de uma página HTML. Ele
          deve ser usado para indicar o assunto mais importante do conteúdo e,
          normalmente, aparece apenas uma vez em cada página.
        </dd>
        <br />
        <li>
          <dt>
            <h2>h2</h2>
          </dt>
        </li>
        <dd>
          O elemento h2 representa um subtítulo importante da página. Ele deve
          organizar uma seção que está abaixo do título principal h1.
        </dd>
        <br />
        <li>
          <dt>
            <h3>h3</h3>
          </dt>
        </li>
        <dd>
          O elemento h3 representa um subtítulo de terceiro nível. Ele organiza
          uma subseção dentro de um conteúdo iniciado por h2.
        </dd>
        <br />
        <li>
          <dt>
            <h4>h4</h4>
          </dt>
        </li>
        <dd>
          O elemento h4 representa um título de quarto nível. Ele identifica uma
          divisão menor dentro da hierarquia do conteúdo.
        </dd>
        <br />
        <li>
          <dt>
            <h5>h5</h5>
          </dt>
        </li>
        <dd>
          O elemento h5 representa um título de quinto nível. Ele organiza
          partes ainda mais específicas de uma seção.
        </dd>
        <br />
        <li>
          <dt>
            <h6>h6</h6>
          </dt>
        </li>
        <dd>
          O elemento h6 representa o menor nível de título HTML. Ele deve ser
          usado para nomear a parte mais específica da hierarquia.
        </dd>
        <br />
      </dl>
    </ol>
  </body>
</html>
