Lista da hierarquia dos títulos HTML

  1. h1

    2. O elemento h1 representa o título principal de uma página HTML. Ele deve ser usado para indicar o assunto mais importante do conteúdo e, normalmente, aparece apenas uma vez em cada página.

  2. h2

    3. O elemento h2 representa um subtítulo importante da página. Ele deve organizar uma seção que está abaixo do título principal h1.

  3. h3

    4. O elemento h3 representa um subtítulo de terceiro nível. Ele organiza uma subseção dentro de um conteúdo iniciado por h2.

  4. h4

    5. O elemento h4 representa um título de quarto nível. Ele identifica uma divisão menor dentro da hierarquia do conteúdo.

  5. h5
    6. O elemento h5 representa um título de quinto nível. Ele organiza partes ainda mais específicas de uma seção.

  6. h6
    7. O elemento h6 representa o menor nível de título HTML. Ele deve ser usado para nomear a parte mais específica da hierarquia.
