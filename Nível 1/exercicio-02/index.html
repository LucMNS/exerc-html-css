Exercício 02 - Conhecendo os títulos HTML

Conteúdos: HTML Headings.

Objetivo: Entender a hierarquia dos títulos HTML.

Atividade:

Crie uma página chamada titulos.html demonstrando os seis níveis de títulos do HTML.

Requisitos:

  • Utilizar <h1> até <h6>.
  • Colocar um pequeno texto abaixo de cada título.
  • Explicar na própria página qual título deve representar o assunto principal.

Desafio:

Crie uma estrutura parecida com o sumário de um livro.
