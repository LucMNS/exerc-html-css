# Exercícios de HTML e CSS

Portfólio de estudos com **30 exercícios práticos**, organizados em cinco níveis. A trilha começa pela estrutura básica do HTML, avança pela organização de conteúdo e termina com os primeiros conceitos de CSS e um projeto de site completo.

> **Projeto de estudo de LucMNS** - atividades orientadas pelo conteúdo do W3Schools.

## Sobre o projeto

Este repositório reúne páginas de apresentação dos exercícios, exemplos funcionais e seus códigos-fonte. Em cada atividade, é possível consultar o objetivo e os requisitos, abrir o resultado no navegador e visualizar o código usado.

O percurso trabalha principalmente com **HTML5 e CSS3**. O exercício 22 introduz JavaScript dentro do HTML, e o exercício 30 integra os conceitos praticados em um site com várias páginas.

## Como abrir

1. Abra esta pasta no Visual Studio Code.
2. Inicie um servidor local usando uma extensão como **Live Server**.
3. Abra o `index.html` da raiz do projeto.
4. Escolha um exercício no menu e use os links da página para ver a atividade ou seu código-fonte.

Use a pasta principal como raiz do servidor. Algumas páginas usam caminhos iniciados por `/` para carregar os estilos e voltar ao menu, por isso, abrir diretamente uma página interna como arquivo pode impedir que esses caminhos funcionem corretamente.

## Organização das pastas

```text
.
├── index.html                # Menu principal com os 30 exercícios
├── css/
│   └── style.css             # Estilos compartilhados do portfólio
├── Nível 1/                  # Exercícios 01–07: fundamentos do HTML
├── Nível 2/                  # Exercícios 08–12: links e imagens
├── Nível 3/                  # Exercícios 13–20: organização do conteúdo
├── Nível 4/                  # Exercícios 21–22: iframe e JavaScript
└── Nível 5/                  # Exercícios 23–30: CSS e projeto integrador
```

Cada pasta `exercicio-XX` contém uma página `index.html` com a apresentação da atividade. As subpastas **Código** guardam páginas para consultar o código-fonte, e as pastas com o nome do exercício guardam os exemplos executáveis e seus recursos, como imagens e folhas de estilo. A estrutura pode variar conforme a atividade.

O exercício 30 reúne o aprendizado em um site fictício para a **TechOsasco Soluções**, com páginas de início, sobre e contato, identidade visual compartilhada, imagens, favicon e folha de estilos externa.

Arquivos principais do site:

- [Página inicial](<Nível 5/exercicio-30/projeto-final/index.html>)
- [Sobre a empresa](<Nível 5/exercicio-30/projeto-final/sobre.html>)
- [Contato](<Nível 5/exercicio-30/projeto-final/contato.html>)

- `Nível 5/exercicio-30/projeto-final/images/` - logo, banner e favicon
