  <body>
    <h1>Entendendo Block e Inline</h1>

    <div class="intro">
      <p>
        Elementos <strong class="inline">block</strong> ocupam toda a largura
        disponível e começam em uma nova linha. Elementos
        <strong class="inline">inline</strong> ocupam apenas o espaço do seu
        conteúdo e permanecem na mesma linha.
      </p>
    </div>

    <!-- div é um elemento block. -->
    <div class="demonstracao bloco">
      <!-- h2 é um elemento block. -->
      <h2>Elementos Block</h2>

      <!-- p é um elemento block. -->
      <p class="bloco">
        Este paragrafo e um elemento block. O proximo paragrafo ficara abaixo
        dele, mesmo que ainda exista espaco na linha.
      </p>

      <!-- p é um elemento block. -->
      <p class="bloco">
        Este e outro elemento block, destacado em azul para facilitar a
        visualizacao da quebra de linha.
      </p>
    </div>

    <!-- div é um elemento block. -->
    <div class="demonstracao">
      <!-- h2 é um elemento block. -->
      <h2>Elementos Inline</h2>

      <!-- p é um elemento block; span, strong e a são elementos inline. -->
      <p>
        Aqui temos um
        <!-- span é um elemento inline. -->
        <span class="inline">span inline</span>, uma
        <!-- strong é um elemento inline. -->
        <strong class="inline">strong inline</strong> e um
        <!-- a é um elemento inline. -->
        <a
          class="inline"
          href="https://developer.mozilla.org/pt-BR/docs/Web/HTML"
          >link inline</a
        >, todos destacados em laranja e seguindo na mesma linha.
      </p>
    </div>

    <div class="legenda">
      <span class="bloco">Azul: elementos block</span>
      <span class="inline">Laranja: elementos inline</span>
    </div>
  </body>
