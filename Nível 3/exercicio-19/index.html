Exercício 19 - Identificando elementos com ID

Conteúdos: HTML Id.

Objetivo: Compreender as diferenças entre id e class.

Atividade:

Desenvolva uma página longa contendo quatro seções de conteúdo distintas.

Requisitos:

  • Cada seção deve possuir um atributo id diferente e único.
  • Criar um menu de navegação no topo da página.
  • Os links do menu devem usar "âncoras" para navegar diretamente para cada seção da página.

Desafio:

Criar um botão ou link de "Voltar ao topo" no final da página.
