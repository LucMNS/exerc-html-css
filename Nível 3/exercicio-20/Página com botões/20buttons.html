Ações disponíveis

Conheça algumas ações que podem ser realizadas com o elemento button.

Cadastrar

Use este botão para adicionar um novo cadastro ao sistema.

Editar

Use este botão para alterar os dados de um cadastro existente.

Excluir

Use este botão para remover um cadastro que não é mais necessário.

Voltar

Use este botão para retornar à página ou à etapa anterior.
